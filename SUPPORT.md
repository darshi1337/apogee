# Getting Help with Apogee

## Questions about setup or use

Open a [Q&A discussion](https://github.com/darshi1337/apogee/discussions/categories/q-a). Setup, model choice, Ollama config, or anything that is not a bug yet belongs there. You will get an answer faster than by opening an issue.

Read the relevant guide first:

- [BROWSERS.md](BROWSERS.md) for per-browser setup
- [OLLAMA.md](OLLAMA.md) for Local Ollama setup
- [MODELS.md](MODELS.md) for model choice

## Bugs and feature requests

Use the [issue templates](https://github.com/darshi1337/apogee/issues/new/choose). The bug form tells you what to include. For a site that extracts badly, use the site support form instead.

## Security vulnerabilities

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) and report privately.

## Response time

One person maintains Apogee in spare time. Expect a first reply within about one week. Issues labeled `first-timers-only` and `good first issue` get priority triage so new contributors are not left waiting.
